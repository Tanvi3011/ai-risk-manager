03 — The Five Agents

Agent Breakdown

Each agent has a specific responsibility. Together they form a complete investigation pipeline.

🔍Detector

Combines ML score, rule signals, and graph risk into a weighted 0-100 risk score. Assigns LOW/MEDIUM/HIGH/CRITICAL level.

Deterministic

🧠Critic

Challenges the Detector's assessment. Asks: "Are these signals actually independent?" Downgrades alerts where shared IP/device is the only real evidence.

LLM + Deterministic

🔎Investigator

When the Critic requests more evidence, this agent expands the graph — finds additional connections, circular transfers, and velocity patterns.

Deterministic

🛡️Guardrails

Final policy gate. Blocks HOLD without 2+ independent evidence sources. Prevents premature ALLOW when ML + graph agree on risk.

Deterministic

📋Explainer

Generates a human-readable case report with: what happened, why it's suspicious, supporting evidence, and recommended action.

LLM + Template
Critic Feedback Loop: Detector → Critic finds weak evidence → Investigator expands graph → Critic reassesses. This loop can run multiple times, each time strengthening or weakening the case.

05 — Dashboard UI

The 5-Page Analyst Console

Designed as a serious internal risk-ops tool — not a flashy AI demo. Information-dense, restrained, data-first.

Page 1

🚨 Risk Queue

Triage alerts by severity. 5 clean metric cards at top, filterable alert rows below.

  • Metric cards: Total, Critical, High, Medium, Critic Downgrades
  • Risk chips (CRITICAL/HIGH/MEDIUM/LOW) with color coding
  • Filter by risk level, sort by score/amount/time
  • Search by transaction ID or account
  • Compact rows: ID, payer→payee, amount, score
Page 2

🔍 Case Investigation

Deep dive into a single transaction. 4 evidence tabs.

  • Header: risk chip + action chip + score bar
  • Device, IP, Amount, Anomaly Score detail cards
  • Tab: Evidence (typed badges: ml/rule/graph/context)
  • Tab: Score Breakdown (ML + Rules + Graph + Critic)
  • Tab: Critic Review (downgrade reasoning)
  • Tab: Triggered Signals (which rules fired)
Page 3

🕸️ Network

Interactive fraud network graph with ring detection.

  • Account risk profile table
Page 4

📊 AI Investigation Trace

Chronological timeline showing what each agent did.

06 — Model Comparison

Unsupervised vs Supervised

Two detection models run in parallel. The supervised model crushes the unsupervised baseline.

Model Precision Recall F1 Flagged False Positives False Negatives
Isolation Forest (unsupervised) 0.850 0.444 0.583 200 30 213
LightGBM (supervised) 0.964 0.564 0.712 224 8 167
Ensemble AND (both agree) 1.000 0.433 0.605 166 0 217
Key insight for judges: LightGBM achieves F1=0.712 with 96.4% precision — catching 56% of fraud with only 8 false positives out of 2,000 test transactions. And when both models agree (AND ensemble), you get 100% precision — zero false positives.
